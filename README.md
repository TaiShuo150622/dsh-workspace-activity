# dsh-workspace-activity

DSH Web GUI 的工作区活跃度显示插件（规划中，尚未实现）。

目标：在侧边栏工作区这一块按活跃程度显示工作区与会话，帮助判断「此刻哪些工作区在动、最近谁在用」。

- 讨论稿 v0.1.0：[docs/discussion/工作区活跃度显示讨论稿-v0.1.0.md](docs/discussion/工作区活跃度显示讨论稿-v0.1.0.md)
- 当前状态：入口位置与活跃度口径待人拍板；代码未开始。

## 讨论稿里已经拍板的部分

| 问题 | 结论 |
| --- | --- |
| 活跃度口径 | 四项都算（最近活动、运行状态、活动量、文件改动） |
| 时间窗 | 可配置，默认 24 小时 |
| 交互 | 给出两种排序选项，未来可扩多种 |
