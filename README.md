# dsh-workspace-activity

DSH Web GUI 的工作区活跃度显示插件（规划中，尚未实现）。

目标：在侧边栏工作区这一块按活跃程度显示工作区与会话，帮助判断「此刻哪些工作区在动、最近谁在用」。

- 讨论稿 v0.1.1：[docs/discussion/工作区活跃度显示讨论稿-v0.1.1.md](docs/discussion/工作区活跃度显示讨论稿-v0.1.1.md)
- 当前状态：方案已定，代码未开始。

## 讨论稿里已经拍板的部分

| 问题 | 结论 |
| --- | --- |
| 第 4 个图标位置 | 先不定，先按 A（侧边栏全局面板入口）做功能 |
| 参考对象 | Codex 桌面应用的 Activity / Priority 视图（已从本机 app.asar 核实） |
| 首版形态 | 活动分节视图（进行中 / 今天 / 昨天 / 更早），不做综合评分 |
| 活跃度口径 | 四项都要算；首版只接现成的两项（最近活动、运行状态），活动量与文件改动放 v1.1 |
| 时间窗 | 可配置，默认 24 小时 |
| 交互 | 给出两种视图模式（活动分节 / 单列排序），未来可扩多种 |
