## 3. 实施中发现的三件事（都已写进文档/README）

1. **卸载要刷新页面**：`plugin_manager remove_bundle` 后 Host 行立即消失，但已打开页面的 Client 半边仍占着 `sidebar.panellist` / `main`，直到刷新页面。E8 的口径改成「Host 行去掉 = 通过；页面侧需刷新」。README 的卸载步骤写明。
2. **v1 改成纯 Client 半边**：插槽标准 props 里直接有 `useSessions` / `useSessionStatus` / `useWorkspaces`，比原稿的 Host 聚合 + RPC + 30s 轮询更小、更实时，也消掉 `/api` 信任边界与 Host 热重载两层风险。详见实施稿「决策修正」。
3. **「等待你」可以做了**：`useSessionStatus` 带 `pendingInteraction`，所以模式 B 多了一个「等待你」分节——原稿说"拿不到"是错的（那是没有走插槽标准 props 时的结论）。

## 4. 需要人看的一页清单（真机，12 条）

在 desktop App 里点侧边栏「活跃度」（在「插件」「自动化任务」下面）：

1. 入口在宽栏与折叠栏都出现，图标是脉冲折线。
2. 点开主区显示面板，不丢当前会话；再点回会话正常。
3. 跑一个会话，面板 30 秒内把它放进「进行中」。
4. 切「按时间」能看到今天/更早分节；「进行中」置顶。
5. 时间窗切 1 小时 / 7 天，纳入范围跟着变。
6. 过滤「只看运行中」后只剩运行中。
7. 分节 chip 能隐藏分节，「恢复默认」能还原。
8. 点会话行能跳到该会话。
9. 窗口内没数据时出现空态文案。
10. 暗色/亮色都清楚，长标题不撑破行。
11. 刷新页面后入口与视图选择（模式/窗口/过滤/分节）仍在。
12. 卸载后刷新页面，入口消失；重装后回来。
